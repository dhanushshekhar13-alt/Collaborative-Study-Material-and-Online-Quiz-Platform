# Module interfaces

Generated by `python scripts/export_interfaces.py` from each module's `__init__.py` and
`service.py`; do not edit by hand. A module's other code may only use what is listed
here for the modules it may call (`docs/architecture.md`, "Module rules"). Each module's
README describes its routes and rules in more detail.


## accounts

Accounts module (FR-01).

- Owns tables: users, profile_pictures
- May call: none

`app.modules.accounts.service`:

- **`AccountDetails`** (dataclass: id, username, email, display_name, role, created_at, is_suspended): What the account owner, or an admin, may see about an account.
- **`Capability`** (enum: `material:upload`, `material:rate`, `channel:create_normal`, `channel:create_authorized`, `channel:approve`, `question:contribute`, `quiz:attempt`, `quiz:publish`, `official_content:manage`, `report:submit`, `report:resolve`, `user:manage`, `admin:dashboard`): A single permitted action, named ``<area>:<verb>``.
- **`DuplicateAccountError`** (exception): A username or email is already registered.
- **`InvalidPictureError`** (exception): An uploaded profile picture was refused; ``str(exc)`` is the user-facing reason.
- **`ProfileDetails`** (dataclass: id, username, display_name, role, bio, institution, created_at, picture_updated_at): The editable, publicly visible part of an account. Email is not included.
- **`ProfilePictureData`** (dataclass: content_type, data, updated_at): A stored profile picture's bytes, type and last change.
- **`Role`** (enum: `student`, `authorized_user`, `admin`)
- **`UserSummary`** (dataclass: id, display_name, role, is_suspended, username): A user as other modules see them: identity, role and suspension, never credentials.
- **`add_reputation(db: Session, user_id: int, points: int) -> None`**: Adjust the cached reputation total (the reputation module owns the event log).
- **`authenticate(db: Session, identifier: str, password: str) -> UserSummary | None`**: Return the user if ``identifier`` (username or email) and ``password`` match.
- **`capabilities_for(role: Role) -> frozenset[Capability]`**: Return everything ``role`` is permitted to do.
- **`count_accounts(db: Session) -> int`**: How many accounts exist, counted in the database.
- **`count_suspended_accounts(db: Session) -> int`**: How many accounts are suspended, counted in the database (NFR-05).
- **`create_user(db: Session, *, email: str, display_name: str, password: str, role: Role=Role.STUDENT, username: str | None=None) -> UserSummary`**: Create a user with a hashed password. Emails and usernames are stored lower-cased.
- **`current_user(credentials: HTTPAuthorizationCredentials | None=Depends(_bearer), db: Session=Depends(get_db))`**: Resolve the caller from their bearer token, or reject the request with 401.
- **`detect_image_type(data: bytes) -> str | None`**: The image type from the file's leading bytes, or ``None`` if it isn't one we accept.
- **`get_account(db: Session, user_id: int) -> AccountDetails | None`**: The account's own details (email, profile fields), or ``None``.
- **`get_profile(db: Session, user_id: int) -> ProfileDetails | None`**: The user's public profile details, or ``None``.
- **`get_profile_picture(db: Session, user_id: int) -> ProfilePictureData | None`**: The user's profile picture, or ``None`` if they have none.
- **`get_user(db: Session, user_id: int) -> UserSummary | None`**: The user with this id, or ``None``.
- **`get_user_by_email(db: Session, email: str) -> UserSummary | None`**: The user with this email (matched case-insensitively), or ``None``.
- **`get_users(db: Session, user_ids: Collection[int]) -> dict[int, UserSummary]`**: Several users at once, keyed by id; unknown ids are left out (S13.1 leaderboard).
- **`get_users_by_username(db: Session, usernames: Collection[str]) -> dict[str, UserSummary]`**: Users by username (case-insensitive), keyed by the lower-cased name (S14.1 mentions).
- **`list_accounts(db: Session) -> list[AccountDetails]`**: Every account, oldest first. Callers must hold ``Capability.USER_MANAGE``.
- **`register_account(db: Session, *, display_name: str, username: str, email: str, password: str) -> AccountDetails`**: Register a Student, rejecting a username or email that is already in use.
- **`remove_profile_picture(db: Session, user_id: int) -> ProfileDetails`**: Delete the user's profile picture (if any) and return the updated profile.
- **`require_capability(capability: Capability) -> Callable`**: Guard a route by what the caller may do rather than by role name.
- **`require_roles(*allowed: Role) -> Callable`**: Guard a route so only ``allowed`` roles reach it; others get 403 Unauthorized.
- **`set_profile_picture(db: Session, user_id: int, data: bytes) -> ProfileDetails`**: Validate and store ``data`` as the user's picture, replacing any earlier one.
- **`set_suspended(db: Session, user_id: int, suspended: bool) -> None`**: Suspend or reinstate an account; raises ``LookupError`` if it does not exist. Caller commits.
- **`update_profile(db: Session, user_id: int, *, display_name: str | object=_UNCHANGED, bio: str | None | object=_UNCHANGED, institution: str | None | object=_UNCHANGED) -> ProfileDetails`**: Change only the fields passed. Blank bio or institution clears it. Caller commits.

## admin

Admin module (FR-14, story S14.2).

- Owns tables: none
- May call: `accounts`, `channels`, `materials`, `moderation`, `notifications`, `questions`

`app.modules.admin.service`:

- **`AdminActionError`** (exception): An admin action that cannot be carried out; ``str(error)`` is the wording.
- **`Conflict`** (exception): The target is already in the requested state (409).
- **`DashboardSummary`** (dataclass: total_users, suspended_users, pending_channel_requests, open_reports, flagged_items): What the admin dashboard opens with: the work waiting for an admin.
- **`NotAllowed`** (exception): The admin action is not permitted on this target (403).
- **`NotFound`** (exception): The user or content an admin action names does not exist (404).
- **`RemovedContent`** (dataclass: target_type, target_id, title, poster_id, channel_id, resolved_report_ids, notified, audit_entry_id): The outcome of removing reported content: what was removed, the reports it closed, whether the poster was told, and the audit entry.
- **`dashboard(db: Session) -> DashboardSummary`**: The admin dashboard counts: users, suspended users, pending channel requests, open reports and flagged items.
- **`reinstate_user(db: Session, *, admin_id: int, user_id: int, reason: str | None=None) -> AccountDetails`**: Lift a suspension; the user can log in again.
- **`remove_content(db: Session, *, admin_id: int, target_type: ReportTarget, target_id: int, reason: str) -> RemovedContent`**: Remove a material or question platform-wide for a rule violation.
- **`suspend_user(db: Session, *, admin_id: int, user_id: int, reason: str | None=None) -> AccountDetails`**: Suspend an account: it can no longer log in, and its open sessions stop working.

## analytics

Analytics module (FR-12).

- Owns tables: performance_attempts, performance_topics (stored figures derived from quiz attempts, always rebuildable from them), recommendation_opens (S12.2)
- May call: `accounts`, `channels`, `materials`, `questions`, `quizzes`
- Subscribes to: `ATTEMPT_SCORED`

`app.modules.analytics.service`:

- **`Dashboard`** (dataclass: attempts, total_score, total_possible, accuracy, subjects, trend, strengths, weak_areas, not_enough_data, empty_message, min_attempts, strong_at, weak_below, topics): Everything the performance dashboard shows (S12.1): totals, subjects, trend, strengths, weak areas and the thresholds used.
- **`Direction`** (enum: `improving`, `steady`, `declining`, `not_enough_data`): Which way a score trend is heading.
- **`PerformanceSummary`** (dataclass: attempts, total_score, total_possible): A user's overall attempts and score totals.
- **`Standing`** (enum: `strong`, `developing`, `weak`, `not_enough_data`): How a topic's accuracy compares with the strong and weak thresholds.
- **`SubjectPerformance`** (dataclass: subject, attempts, total_score, total_possible, accuracy, topics, trend): One subject's totals, its topics and its trend.
- **`TopicPerformance`** (dataclass: subject, topic, attempts, total_score, total_possible, accuracy, standing): One topic's results with its accuracy and standing.
- **`TopicTotals`** (dataclass: subject, topic, attempts, total_score, total_possible): Stored score totals for one subject and topic.
- **`Trend`** (dataclass: points, slope, direction, line_start, line_end): Scores over time with the least-squares slope and its direction.
- **`TrendPoint`** (dataclass: attempt_id, quiz_id, quiz_title, subject, topic, submitted_at, percentage, running_accuracy): One scored attempt on a trend line, with the running accuracy after it.
- **`classify(attempts: int, accuracy: float | None) -> Standing`**: Strong, developing or weak by accuracy; too few attempts are never labelled.
- **`dashboard(db: Session, user_id: int) -> Dashboard`**: Performance by subject and topic with trends and strong/weak topics.
- **`rebuild_user(db: Session, user_id: int) -> None`**: Discard the user's stored figures and rebuild them from raw attempts.
- **`recommendations_for(db: Session, user_id: int, *, limit: int=12)`**: Materials, questions and quizzes for the user's weak topics, best first.
- **`recompute(db: Session, user_id: int) -> dict[tuple[str, str], TopicTotals]`**: The user's per-topic figures derived from raw attempts alone (writes nothing).
- **`record_attempt(db: Session, attempt_id: int) -> None`**: Fold one scored attempt into its user's figures (the ``ATTEMPT_SCORED`` handler).
- **`record_recommendation_open(db: Session, user_id: int, item_type: str, item_id: int) -> None`**: Remember that the user opened a recommended item, to de-prioritise it later.
- **`stored(db: Session, user_id: int) -> dict[tuple[str, str], TopicTotals]`**: The user's per-topic figures as currently stored.
- **`summary_for_user(db: Session, user_id: int) -> PerformanceSummary`**: Overall attempt count and points from the stored figures.
- **`sync_user(db: Session, user_id: int) -> int`**: Reconcile the user's stored figures with their raw attempts; returns rows fixed.
- **`trend(points: list[TrendPoint]) -> Trend`**: Least-squares line through the attempt percentages, in attempt order.

- **`delete_post(db: Session, post_id: int) -> None`**: Delete a post (no-op if it is already gone).
- **`describe_channel(db: Session, channel_id: int) -> ChannelSummary | None`**: A channel with its member count, for channel pages and lists.
